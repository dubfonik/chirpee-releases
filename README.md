# Chirpee

Dictation in any Mac app: hold Right Option, speak, let go, and Chirpee types what you said where your cursor is.

## Install

1. Download [Chirpee.zip](https://github.com/dubfonik/chirpee-releases/releases/latest/download/Chirpee.zip).
2. Open it and follow `Read me first.txt`.

Needs a Mac with Apple Silicon (M1 or later) and macOS 14 or later.

## Updates

Chirpee updates itself, and shows what's new before it installs anything. See [Releases](https://github.com/dubfonik/chirpee-releases/releases) for every version's notes.

This repo holds only the update files Chirpee downloads (`appcast.xml` and the zipped app for each version).
